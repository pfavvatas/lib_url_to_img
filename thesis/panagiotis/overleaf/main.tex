% English Abstract
\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

This thesis presents {\name}, a research platform for analyzing structural similarities between websites. The system processes web pages by examining their DOM structure and CSS styling, then uses machine learning to group similar elements together.

The core problem tackled here is building a system that can automatically analyze web pages at different DOM depths, ranging from level 1 to level 10. Users can choose between two approaches: analyzing all URLs together as one dataset, or processing them separately by domain for comparison. The system extracts both structural information from the DOM tree and visual styling from CSS properties, combining these into a single representation for analysis.

The clustering approach uses HDBSCAN (Hierarchical Density-Based Spatial Clustering of Applications with Noise) along with DBCV (Density-Based Cluster Validation) to group similar webpage elements. The system also handles outliers by reassigning them to appropriate clusters when possible.

For research purposes, the platform includes an experiment management component that allows users to run multiple test scenarios with different URL combinations, DOM levels, and processing modes. A caching system stores processed results from individual URLs, which speeds up repeated analyses. The cache includes TTL settings and tracks efficiency metrics to show how much processing time is saved.

The technical implementation uses React for the user interface, Flask for the API layer, and Python for the core processing logic. The system produces visualizations through Gnuplot integration, generating charts and data files suitable for academic work. Users can access a results archive to compare different experiments and track performance over time.

The system outputs color-coded HTML files that show structural similarities between websites. It also generates similarity matrices using cosine similarity calculations and provides detailed timing information about processing performance and cache usage.

Testing shows that the system effectively groups web content based on structural characteristics. It can handle multiple websites simultaneously and produces meaningful clusters based on DOM hierarchy and CSS styling patterns. The performance data helps researchers optimize their analysis workflows.

\textit{The complete system implementation is available at: \url{https://github.com/pfavvatas/lib_url_to_img}}
