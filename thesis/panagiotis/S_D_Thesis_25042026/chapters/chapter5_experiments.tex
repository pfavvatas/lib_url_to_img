\chapter{Experiments and Evaluation}
\label{chap:experiments}

This chapter presents a comprehensive experimental evaluation of the S\textsuperscript{4}D system, demonstrating its effectiveness in web similarity analysis and clustering. The experiments validate the system's performance across multiple dimensions, including accuracy, scalability, and practical applicability.

\section{Experimental Design}
\label{sec:experimental-design}

The experimental evaluation was designed to assess the S\textsuperscript{4}D system across several key dimensions:

\subsection{Research Questions}
\label{subsec:research-questions}

\begin{enumerate}
    \item \textbf{RQ1}: How effectively does the S\textsuperscript{4}D system cluster websites based on structural and stylistic similarity?
    \item \textbf{RQ2}: What is the optimal analysis level for balancing clustering quality and computational efficiency?
    \item \textbf{RQ3}: How does the system's performance scale with increasing numbers of URLs?
    \item \textbf{RQ4}: How does S\textsuperscript{4}D compare to traditional clustering approaches for web similarity analysis?
\end{enumerate}

\subsection{Evaluation Metrics}
\label{subsec:evaluation-metrics}

The evaluation employs multiple complementary metrics:

\begin{itemize}
    \item \textbf{DBCV Score}: Density-Based Cluster Validation for clustering quality assessment
    \item \textbf{Processing Time}: Computational efficiency measurement
    \item \textbf{Memory Usage}: Resource consumption analysis
    \item \textbf{Success Rate}: Percentage of successfully processed URLs
\item \textbf{Similarity Accuracy}: Comparison with ground truth classifications
\end{itemize}

\section{Statistical Validation}
\label{sec:statistical-validation}

Statistical hypothesis testing confirms the significance of observed improvements:

\subsection{Significance Testing}
\label{subsec:significance-testing}

\textbf{Hypothesis 1}: S\textsuperscript{4}D clustering significantly outperforms random clustering
\begin{itemize}
    \item \textbf{Test}: Paired t-test with p < 0.001
\item \textbf{Effect size}: 2.34 (large effect)
    \item \textbf{Conclusion}: Highly significant improvement over baseline
\end{itemize}

\textbf{Hypothesis 2}: Multi-level analysis improves clustering quality
\begin{itemize}
    \item \textbf{Test}: One-way ANOVA with F = 15.67, p < 0.001
    \item \textbf{Post-hoc}: Level 5 significantly superior to shallow levels
    \item \textbf{Conclusion}: Depth of analysis is crucial for quality
\end{itemize}

\subsection{Cross-Validation Results}
\label{subsec:cross-validation}

Five-fold cross-validation confirms the robustness of the S\textsuperscript{4}D approach across different website samples. The detailed cross-validation results (Appendix~\ref{appendix:experimental-data}, Table~\ref{tab:cross-validation}) demonstrate consistent performance with low variance.

\textbf{Cross-Validation Summary}:
\begin{itemize}
    \item \textbf{Mean DBCV}: 0.72 ± 0.023
\item \textbf{Mean Accuracy}: 89.7\% ± 1.89\%
    \item \textbf{Consistency}: Low standard deviation indicates robust performance
    \item \textbf{Generalizability}: Performance stable across different website samples
\end{itemize}

\section{Error Analysis and Limitations}
\label{sec:error-analysis}

\subsection{Failure Case Analysis}
\label{subsec:failure-cases}

Analysis of processing failures reveals common patterns and limitations. The detailed failure analysis (Appendix~\ref{appendix:experimental-data}, Table~\ref{tab:failure-analysis}) identifies key improvement areas.

\textbf{Primary Failure Categories}:
\begin{itemize}
    \item \textbf{Timeout Issues} (42.9\%): Heavy JavaScript applications
    \item \textbf{DOM Parsing} (28.6\%): Malformed HTML and dynamic content
    \item \textbf{CSS Extraction} (17.9\%): Complex CSS rules and imports
    \item \textbf{Network Errors} (10.7\%): Connection and accessibility issues
\end{itemize}

\subsection{Quality Degradation Factors}
\label{subsec:quality-factors}

Several factors negatively impact clustering quality:

\begin{itemize}
    \item \textbf{Excessive DOM depth}: 15\% quality reduction for depths >10 levels
    \item \textbf{Dynamic content loading}: 23\% quality reduction for heavily dynamic sites
\item \textbf{Minimal CSS styling}: 12\% quality reduction for unstyled content
\item \textbf{Mixed content types}: 8\% quality reduction for heterogeneous pages
\end{itemize}
